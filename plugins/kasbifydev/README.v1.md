# KasbifyDev v0.1 status

KasbifyDev packages the repository's remote Odoo 19 MCP server for ChatGPT/Codex plugin use.

Backend: `https://odoo-mcp-19-cff81cc6.alpic.live` (Streamable HTTP).

The package contains the plugin manifest, Odoo skill, ChatGPT App binding placeholder, binder, validator, installation notes, registration values, security notes, and CI validation.

The only remaining account/workspace-scoped step is registering the ChatGPT App and replacing `REPLACE_WITH_CHATGPT_APP_ID` with the canonical App ID.
